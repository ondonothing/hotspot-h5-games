# P0：热点Quiz变形执行指南（最高优先级）

## 对标产品
病毒人格测试、角色测试、热点问答（SBTI类、角色匹配类）

## 我们的变形方式
使用现有 `templates/quiz/index.html`，只替换配置：
- 标题 → 当前热点相关
- 题目 → 热点相关问题（3-8题即可）
- 结果称号 → 强分享的热点称号 + 描述

## 标准输出物
1. design.md（对标说明 + 题目设计 + 称号设计）
2. 修改后的 index.html
3. compliance.md
4. 部署后链接
5. 推广文案（结果导向）

## 广告位
保持游戏结束自然断点，接入GameMonetize SDK。

## 弃用标准
3天内访问低且分享率接近0 → 弃用。
