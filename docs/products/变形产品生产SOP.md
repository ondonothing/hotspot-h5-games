# 变形产品生产SOP（标准化操作流程）

适用于所有P0/P1/P2变形产品。

## 标准步骤
1. **Trend Scout** 输出候选 + 推荐变形模式 + 选题检查表打分
2. **Boss** 选定热点与变形类型（Quiz / Challenge / 工具等）
3. **Game Designer** 输出设计文档（对标说明 + 具体变形点 + 称号/结果设计）
4. **Compliance** 审查
5. **Coder** 复制对应模板到 games/新目录，修改配置，预留广告位
6. **Deploy** 部署到Vercel，记录链接
7. **Publisher** 提交GameMonetize（账号就绪后）
8. **Marketer** 输出社群文案 + 短视频脚本
9. **Operator** 监控3-7天，给出弃用/继续建议

## 强制要求
- 每个产品必须有独立 games/ 目录
- 全过程文档实时提交GitHub
- 使用热点选题快速检查表过滤低分热点
