# P1：物理/堆叠类变形指南（Plinko / Tower Stack 等）

## 对标成功模式
- Plinko（2025年病毒物理小游戏代表）
- Tower Stack / 对齐堆叠
- Color Match / 颜色匹配

## 为什么适合我们
玩法成熟、理解成本极低、结果直观、易做短视频素材，可用纯Canvas实现。

## 变形方式
1. 保留核心物理/操作循环
2. 视觉元素换成热点相关图标/颜色/文案
3. 得分与称号做成热点身份标签
4. 结果页强化分享欲

## 技术建议
- 优先用现有轻量Canvas或简单物理库
- 控制体积，适配移动端
- 广告位放在游戏结束或关卡结束

## 执行时机
P0（Quiz/Challenge）验证闭环并有初步数据后，再启动P1模板开发。

## 产出要求
- 可复用的基础模板（templates/plinko 或 templates/stack）
- 热点皮肤配置说明
- 完整生产检查清单走完
