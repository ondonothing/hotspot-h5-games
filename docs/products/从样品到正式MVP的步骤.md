# 从样品到正式MVP的步骤

账号就绪后，推荐路径：

1. **选样品**  
   从 quiz / challenge / clicker 三个完整样品中选一个作为底版。

2. **选热点**  
   用热点选题快速检查表打分，选可套用模板、分享欲强、合规低风险的热点。

3. **改文案**  
   复制样品目录 → 改 title / 题目 / 称号 → 本地试玩确认。

4. **走SOP**  
   设计文档 → Compliance → 部署 → 提交GameMonetize → 推广素材。

5. **监控**  
   3-7天数据，按弃用标准决定去留。

目标：尽量在账号就绪当天或次日完成第一个可提交版本。
