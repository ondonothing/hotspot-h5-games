# 热点选题快速检查表（Trend Scout + Boss 使用）

在选定热点做变形产品前，快速打分（1-5分）：

| 检查项 | 分数 | 说明 |
|--------|------|------|
| 热度持续性 |  | 至少能撑1-3天 |
| 可套用现有模板 |  | Quiz/Challenge/Clicker是否直接可用 |
| 结果页分享欲 |  | 称号/对比是否容易让人截图发 |
| 合规风险 |  | 越低越好（1分风险高，5分安全） |
| 受众广度 |  | 是否大众可理解 |
| **总分** |  | 建议≥20分再启动 |

最终决策由Boss拍板。低分热点直接放弃，不进入开发。
