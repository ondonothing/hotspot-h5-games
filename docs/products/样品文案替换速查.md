# 样品文案替换速查

把样品改成真实热点时，优先改这些位置（打开对应 index.html 搜索即可）。

## Quiz（sample-quiz-deform-complete）
| 位置 | 说明 |
|------|------|
| GAME_CONFIG.title | 游戏标题 |
| GAME_CONFIG.questions[].q | 题干 |
| GAME_CONFIG.questions[].options | 选项 |
| GAME_CONFIG.titles[].title / desc | 结果称号与描述 |
| 页面主标题文案 | 若 HTML 中有写死标题一并改 |

## Challenge（sample-challenge-deform-complete）
| 位置 | 说明 |
|------|------|
| 页面标题/副标题 | 热点反应力等文案 |
| CONFIG.challenges[].text | 挑战题干 |
| CONFIG.challenges[].correct / wrong | 对错按钮文案 |
| endGame 中的 title 字符串 | 结果称号分段 |
| 分享文案中的游戏名 | 保持一致 |

## Clicker（sample-clicker-deform-complete）
| 位置 | 说明 |
|------|------|
| 页面标题/说明 | 热点手速等 |
| 按钮文字（如「点热点!」） | 可改成热点相关动词 |
| 结果称号分段逻辑中的字符串 | 需要热身/信息猎手等 |
| 分享文案中的游戏名 | 保持一致 |

## 改完后
1. 本地刷新试玩一遍
2. 走样品本地测试检查清单
3. 更新 design.md 说明本次热点差异
4. 重新过 compliance（不可照搬样品结论）
