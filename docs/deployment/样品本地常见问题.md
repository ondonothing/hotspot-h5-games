# 样品本地常见问题

**Q：双击 index.html 没反应或样式乱？**  
A：用浏览器打开（Chrome/Edge）。若用文件协议有限制，可用简易静态服务，或直接拖到浏览器窗口。

**Q：点了没分数/没跳转？**  
A：刷新页面重试；检查是否改配置时弄丢了括号或逗号（JSON/JS对象语法）。

**Q：手机打开布局异常？**  
A：确认有 viewport meta；用手机浏览器直接打开部署后的链接更准确。

**Q：改完文案结果称号不对？**  
A：检查分数区间（min/max）是否覆盖所有得分；Challenge/Clicker 看 endGame 里的分段条件。

**Q：准备正式提交还缺什么？**  
A：Game ID、SDK接入、部署URL、publish记录。见第1天行动手册。
