# 部署快速检查清单

每次部署前/后对照：

## 部署前
- [ ] index.html 在目标目录根下
- [ ] 所有资源使用相对路径（无绝对本地路径）
- [ ] 本地浏览器打开可正常运行
- [ ] 移动端视口已设置（viewport meta）
- [ ] 广告位注释清晰，便于后续替换SDK

## 部署后
- [ ] 获得公开可访问URL
- [ ] 手机浏览器实测可打开
- [ ] 记录URL到对应 games/ 目录的 deploy.md
- [ ] 生成短链（可选）与二维码（用于社群）

## 推荐平台
优先 Vercel（见 Vercel部署指南.md），也可用 Netlify / Cloudflare Pages。

部署记录必须进仓库。
