# 产品模式与对标变形策略（正式执行版）

**版本**：v1.0  
**日期**：2026-10-30  
**目标**：用成熟成功模式进行快速变形，匹配多Agent全流程，实现快速验证与变现。

## 一、核心策略

不做从零原创高难度玩法，而是：
1. 找到已验证高流量/高分享的产品模式
2. 用热点皮肤或轻改进行变形
3. 通过多Agent流水线快速产出
4. 3-7天数据决定弃用或系列化

## 二、优先品类（执行顺序）

### P0：热点皮肤小游戏 + 结果分享测试（立即执行）
- 已有模板：Quiz / Challenge / Clicker
- 对标：病毒人格测试、限时挑战、反应类
- 变形方式：替换文案、称号、皮肤为当前热点
- 变现：GameMonetize优先 → CrazyGames / Poki

### P1：物理/堆叠轻游戏变体
- 对标：Plinko、Tower Stack、Color Match
- 变形：热点图标替换 + 得分文案热点化
- 需要新增简单Canvas模板

### P2：超简单工具 + 热点包装
- 对标：随机转盘、决策工具、对比工具
- 变形：做成热点决策器 / 匹配测试
- SEO + 社群双通道

### P3：画线/解谜轻变体（有数据后再做）

## 三、成功对标数据摘要

- Poki：月活约1亿，单月播放10亿+
- CrazyGames：月活数千万，广告分成可观
- 病毒测试：单日讨论可达千万级
- 简单工具：单站月访问百万～千万，纯广告月入可观
- TikTok素材：画线救宠、推箱子等曝光数千万

## 四、变形执行标准

每个新产品必须包含：
- 明确对标的成熟模式
- 热点/皮肤差异点
- 结果页分享钩子
- 广告自然断点
- 3-7天弃用标准

## 五、与多Agent流程的映射

- Trend Scout：优先筛选“可变形成熟模式”的热点
- Game Designer：输出“对标X + 变形点Y”的设计文档
- Coder：优先复用/轻改现有模板
- 其余流程保持不变
