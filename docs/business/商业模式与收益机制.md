# 商业模式与收益机制

## 核心模式
热点驱动的境外 H5 小游戏工厂。

- 选材：热点事件 / 话题（简单、强分享、合规）
- 形式：轻量 H5（答题、挑战、合成、点击类）
- 部署：境外域名 + Vercel / Netlify / Cloudflare Pages（零 ICP）
- 变现：门户广告分成（IAA）为主
- 推广：社群冷启动 + 抖音/小红书内容种草

## 收益机制
主要依靠插页广告 + 激励视频广告。

收入 ≈ 广告展示次数 × 填充率 × eCPM

分成平台：
- GameMonetize：45%（自己发布可达 90%），最低 $30
- CrazyGames：广告分成（赛事参考约 60%），最低 €100
- Poki：直接流量 100%，门户流量约 50/50

资金流向：
门户/AdSense → PayPal / Tipalti → Payoneer / WorldFirst / PingPong → 国内账户

## 关键原则
- 速度优先（24-48 小时从热点到可玩链接）
- 合规底线（不碰敏感内容）
- 数据驱动（3-7 天无起色立即弃用）
- 持续迭代与规模化
