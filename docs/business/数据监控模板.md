# 简单数据监控模板（Operator使用）

每个游戏建议记录以下指标（可用表格或Markdown）：

| 日期 | 访问量 | 平均时长 | 分享次数 | 广告展示 | 预估收入 | 来源备注 | 决策建议 |
|------|--------|----------|----------|----------|----------|----------|----------|
|      |        |          |          |          |          |          |          |

## 弃用阈值参考
- 连续3天日访问 < 50 且无上升趋势
- 7天总收入接近0
- 分享率极低

达到弃用条件时，Operator 输出建议，Boss 最终决策。
