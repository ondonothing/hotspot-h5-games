# Poki 注册与接入手册

Poki 质量要求最高，流量质量好，适合经过验证的优质游戏。

## 一、申请流程

1. 访问：https://developers.poki.com
2. 填写提交表单（团队信息 + 游戏信息）
3. 提供可玩链接或游戏视频 + 至少 3 张实际游戏截图
4. 人工审核，通过后进入正式开发者平台

## 二、硬性技术要求

- 16:9 画布，完整覆盖
- 支持 Desktop / Mobile / Tablet
- 初始加载尽量小（目标 < 8MB）
- 无外部请求（字体、资源全部打包）
- 正确集成 Poki SDK
- 无其他广告、无外链品牌（工作室 logo 可在 loading 页）
- 支持 Incognito 模式（localStorage 需 try/catch）

## 三、测试阶段

上传后会经历：
1. 内容审核
2. Playtesting
3. Web Fit Test
4. 最终审核

通过后全球上线，直接流量 100% 分成，Poki 带来的流量约 50/50。
