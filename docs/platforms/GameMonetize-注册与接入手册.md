# GameMonetize 注册与接入完整手册（优先完成）

**优先级最高**，最适合入门验证，审核相对宽松，最低提现 $30，支持 PayPal / USDT。

## 一、注册账号

1. 打开浏览器访问：https://gamemonetize.com
2. 点击右上角 **Login / Register** 或直接进入开发者入口
3. 选择注册（Sign Up）
4. 填写信息：
   - Email（建议使用专用邮箱）
   - Password
   - 其他必要信息（姓名等）
5. 完成邮箱验证（查收验证邮件并点击确认）

注册成功后进入后台 Dashboard。

## 二、添加游戏并获取 Game ID

1. 登录后进入 **My Games** 或点击 **Add Game**
2. 填写游戏标题（可先随便填，后续可改）
3. 创建成功后，进入该游戏详情页，复制 **Game ID**（非常重要，SDK 需要用到）

## 三、集成 SDK（核心步骤）

推荐使用官方 HTML5/JS SDK。

### 基础集成步骤：

1. 在游戏 HTML 中引入 SDK（或下载后本地引入）
2. 初始化时传入你的 Game ID
3. 在合适的时机调用广告接口（推荐位置）：
   - 游戏结束
   - 关卡切换
   - 玩家主动点击“看广告复活/获取提示”

**关键要求**：
- 广告播放前必须暂停游戏并静音
- 广告结束后恢复游戏
- 正确处理广告失败的情况（不能卡死游戏）

（具体代码模板我会在 `templates/` 和后续游戏中直接提供）

## 四、上传游戏

1. 将完整游戏文件打包成 **ZIP**
   - 根目录必须包含 `index.html`
   - 所有资源使用相对路径
2. 在游戏后台上传 ZIP 包
3. 点击 **Verify Game** 验证 SDK 是否正确集成
4. 验证通过后点击 **Request Activation** 提交审核

## 五、收款设置

1. 进入账户设置 / Payout 相关页面
2. 绑定 **PayPal**（推荐）或 USDT（ERC20）
3. 达到最低 $30 后可申请提现
4. 结算周期：Net 30（上月收入大约在次月 25 天内到账）

## 六、注意事项

- 内容必须合规（无色情、赌博、政治敏感、侵权）
- 游戏需支持移动端
- 不要在游戏中放置其他广告网络
- 审核通常较快，通过后即可开始获得分成（45%，如果自己同时是发布者可达 90%）
