# GameMonetize 详细操作补充（阶段1支持）

优先级最高，建议第一个完成。

## 注册后必做清单

1. 登录后台，确认邮箱已验证
2. 进入 Add Game / My Games
3. 先创建一个占位游戏（标题随便填），获取 **Game ID**
4. 保存 Game ID，后续SDK集成必须用到
5. 进入账户/收款设置，绑定 PayPal（推荐）或 USDT
6. 记录账号状态到本仓库（更新阶段1清单）

## SDK 集成关键点（Coder使用）

- 官方HTML5/JS SDK
- 初始化时传入 Game ID
- 在游戏结束、复活、关卡切换等自然断点调用广告
- 广告播放前必须暂停游戏 + 静音
- 广告结束或失败后恢复游戏，不能卡死

## 上传要求

- ZIP包根目录必须有 index.html
- 使用相对路径
- 验证通过后再 Request Activation
