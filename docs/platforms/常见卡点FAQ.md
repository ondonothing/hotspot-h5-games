# 常见卡点FAQ（注册与接入阶段）

## GameMonetize
**Q：收不到验证邮件？**  
A：检查垃圾邮件；换邮箱重试；稍等几分钟再刷新。

**Q：找不到 Game ID？**  
A：创建游戏后进入该游戏详情页，通常在游戏信息或嵌入代码区域可见。

**Q：收款绑定失败？**  
A：确认 PayPal 账号地区与邮箱正确；USDT 注意选择正确网络（多为 ERC20）。

**Q：上传后验证不通过？**  
A：检查是否根目录有 index.html、相对路径、SDK 是否正确初始化。

## CrazyGames
**Q：Billing 卡住？**  
A：可先选 Hold Payments，不阻塞游戏提交。

**Q：Basic Launch 和 Full Launch 区别？**  
A：Basic 可先上线测数据；Full 才正式接入广告变现。

## 通用
**Q：国内访问 Vercel 链接慢或不稳定？**  
A：正常现象。验证阶段可接受；后续可考虑 Cloudflare 或自有境外域名优化。

**Q：什么时候可以开始第一个游戏？**  
A：GameMonetize 注册成功并拿到 Game ID 即可立即启动。
