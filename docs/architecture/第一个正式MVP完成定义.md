# 第一个正式MVP完成定义（Definition of Done）

同时满足以下条件，即视为第一个正式MVP完成：

1. **有独立正式目录**（非样品目录），命名符合规范
2. **可公开访问的游玩链接**（已部署）
3. **已接入真实 Game ID**（或至少完成提交所需的集成步骤）
4. **已在 GameMonetize（或选定门户）完成提交**
5. **design / compliance / deploy / publish / marketing / data 文档齐全并在仓库**
6. **至少完成一次对外推广尝试**（社群或短视频）
7. **data.md 开始有记录**

未满足前不算闭环完成；满足后进入第1周运营清单观察期。
