# 合规规则库（Compliance Agent 参考）

## 红线（直接拒绝）
- 涉及政治敏感、国家领导人、政治事件负面解读
- 色情、低俗、软色情
- 赌博、博彩、资金盘相关
- 暴力血腥、仇恨、歧视
- 明显侵犯版权的素材或玩法照搬

## 高风险（需修改或谨慎）
- 借热点借势但容易引战
- 涉及宗教、民族敏感
- 虚假宣传、夸大效果
- 诱导分享但文案违规

## 相对安全（优先）
- 娱乐、生活、反应力、知识问答、轻挑战
- 中性热点（天气、节日、体育、科技产品、流行语）
- 结果页正向或幽默称号

## 执行要求
Compliance 必须给出明确结论，不能模糊。  
高风险题材必须有修改方案才能进入开发。
