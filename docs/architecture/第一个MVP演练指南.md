# 第一个MVP演练指南（阶段2准备）

阶段0底座已完成，阶段1账号准备中。本文件用于正式启动第一个热点游戏时的演练。

## 目标
用真实热点跑通一次完整多Agent流水线，验证从选题到可玩链接到门户提交的闭环。

## 演练步骤（严格按检查清单）

1. **Boss启动**  
   指令：“启动第一个MVP热点游戏生产”

2. **Trend Scout**  
   使用搜索工具抓取当前热点，输出3-5个候选 + 评分

3. **Boss选定**  
   拍板1个最适合的热点（简单、强分享、低合规风险）

4. **Game Designer**  
   输出完整设计文档（玩法、结果页、广告断点、分享钩子）

5. **Compliance**  
   审查并给出结论

6. **Coder**  
   基于 templates/ 生成代码，提交到 games/mvp-001/

7. **Deploy**  
   部署到Vercel，输出可玩链接 + 短链

8. **Publisher**  
   提交GameMonetize（需账号就绪）

9. **Marketer**  
   生成社群文案与短视频脚本

10. **Operator**  
    开始数据监控

## 成功标准
- 可玩链接上线
- 代码与全过程文档已进GitHub
- 至少完成一个门户提交
- 有初步访问数据

准备好账号后即可正式启动本演练。
