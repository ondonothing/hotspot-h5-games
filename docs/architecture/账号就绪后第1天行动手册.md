# 账号就绪后第1天行动手册

目标：当天或次日完成「可玩链接 + 已提交门户」的最小闭环。

## 上午（或收到 Game ID 后立即）
1. 把 Game ID 和收款状态更新到 `docs/platforms/阶段1-账号注册执行清单.md`
2. 打开 `docs/products/从样品到正式MVP的步骤.md`
3. 任选一个样品作为底版（推荐 Quiz 或 Challenge）
4. 用 `docs/products/热点选题快速检查表.md` 选1个当前热点（总分建议≥20）

## 中段
5. 复制样品目录为 `games/YYYYMMDD-热点简称/`
6. 只改文案（title / 题目 / 称号），本地打开试玩
7. 走 `docs/deployment/样品本地测试检查清单.md`
8. 按 `docs/platforms/拿到GameID后的SDK接入检查清单.md` 接入 SDK
9. 按 `docs/deployment/样品部署到Vercel最短路径.md` 部署，填写 deploy.md

## 收尾
10. 在 GameMonetize 上传并提交，填写 publish.md
11. 用样品自带 marketing.md 改一版社群文案发出去测试
12. 开始在 data.md 记数据，进入 3-7 天观察

## 原则
速度优先，先闭环再优化。一个可提交版本 > 完美版本。
