# 单个游戏生产检查清单（标准化流程）

每个新热点游戏必须按此清单执行，并在 games/游戏名/ 下保存全过程文档。

## 1. 启动
- [ ] Boss 发出启动指令
- [ ] 创建 games/游戏代号/ 目录

## 2. 热点与选题
- [ ] Trend Scout 使用搜索工具输出候选
- [ ] Boss 选定最终热点
- [ ] 保存选题文档

## 3. 设计
- [ ] Game Designer 输出完整设计文档
- [ ] Compliance 审查通过
- [ ] 设计文档存档

## 4. 开发
- [ ] Coder 基于模板生成代码
- [ ] 预留广告位
- [ ] 本地可运行验证
- [ ] 代码提交GitHub

## 5. 部署
- [ ] Deploy 部署到Vercel等
- [ ] 获得可玩链接
- [ ] 生成短链/二维码
- [ ] 记录部署信息

## 6. 提交门户
- [ ] Publisher 提交GameMonetize（优先）
- [ ] 记录Game ID与提交状态

## 7. 推广
- [ ] Marketer 生成社群文案 + 短视频脚本
- [ ] 执行分层推广

## 8. 运营
- [ ] Operator 监控数据
- [ ] 3-7天后给出弃用/迭代建议
- [ ] Boss 最终决策

所有步骤文档必须实时提交本仓库。
