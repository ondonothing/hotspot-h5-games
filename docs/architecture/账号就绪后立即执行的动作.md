# 账号就绪后立即执行的动作

当你反馈 GameMonetize 注册成功 + Game ID 后，按以下顺序立刻执行：

1. **更新状态**  
   修改阶段1清单，勾选已完成项，提交仓库。

2. **Boss 发出指令**  
   “启动第一个MVP热点游戏生产”

3. **Trend Scout**  
   立即执行热点捕捉（使用搜索工具），输出候选。

4. **选定 + 设计 + 合规**  
   快速走完 Designer → Compliance。

5. **Coder**  
   基于模板生成代码，写入 games/ 真实目录，预埋真实 Game ID。

6. **Deploy**  
   部署到 Vercel，输出可玩链接。

7. **Publisher**  
   指导完成 GameMonetize 上传与提交。

8. **Marketer + Operator**  
   输出推广素材并开始监控。

全程文档实时进仓库。  
目标：从账号就绪到第一个可玩+可提交版本，尽量控制在数小时内。
