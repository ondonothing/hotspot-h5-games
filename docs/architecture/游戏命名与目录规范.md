# 游戏命名与目录规范

## 目录命名推荐
格式：`YYYYMMDD-简短热点名` 或 `mvp-序号-简短名`

示例：
- `20261026-热点挑战`
- `mvp-001-reaction`
- `mvp-002-quiz-hot`

## 目录内标准文件
```
games/游戏名/
├── index.html          # 游戏主文件
├── design.md           # 设计文档
├── compliance.md       # 合规结论
├── deploy.md           # 部署链接与记录
├── publish.md          # 门户提交记录
├── marketing.md        # 推广素材
└── data.md             # 运营数据
```

## 规则
1. 每个游戏独立目录，禁止混放
2. 全过程文档必须进对应目录并提交GitHub
3. 弃用游戏可在目录名后加 `-archived` 或移动到 `games/archived/`

保持规范，方便后期规模化管理与复盘。
