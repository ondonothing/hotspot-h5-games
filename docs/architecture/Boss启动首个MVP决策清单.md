# Boss 启动首个MVP决策清单

在发出“启动第一个正式MVP”指令前，Boss 确认：

## 硬条件
- [ ] GameMonetize 已注册并拿到 Game ID
- [ ] 收款方式已绑定
- [ ] 至少一个样品本地可玩且文档齐全

## 选题
- [ ] 已用热点选题快速检查表打分
- [ ] 总分达标（建议≥20）
- [ ] 明确使用哪种变形：Quiz / Challenge / Clicker

## 执行安排
- [ ] 指定底版样品目录
- [ ] 确认按《第1天行动手册》推进
- [ ] 确认验收标准为《第一个正式MVP完成定义》

全部勾选后，输出指令：
“启动第一个正式MVP：热点=XXX，类型=Quiz/Challenge/Clicker，底版=对应样品目录”
