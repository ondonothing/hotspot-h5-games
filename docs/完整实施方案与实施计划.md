## 一、商业模式总结（定稿）

**核心模式**：热点驱动的境外H5小游戏自动化工厂

- **选材**：热点事件/话题（简单、强分享性、合规）
- **产品形态**：轻量级H5网页游戏（答题、挑战、点击、合成类）
- **技术架构**：纯前端 HTML/JS/Canvas，境外域名 + Vercel/Netlify/Cloudflare Pages 部署（零ICP备案）
- **变现**：以门户广告分成（IAA）为主（GameMonetize → CrazyGames → Poki）
- **推广**：社群冷启动优先 + 抖音/小红书内容种草辅助
- **自动化**：多Agent大模型协作全流程（热点捕捉→设计→生成→部署→提交→运营）
- **资金流**：门户收入 → PayPal/Tipalti → Payoneer/WorldFirst等 → 国内账户

**关键原则**：
1. 速度优先（热点到可玩链接目标24-48小时）
2. 合规底线（不碰违法、敏感、侵权内容）
3. 数据驱动（3-7天无起色立即弃用）
4. 先验证再规模化
5. 账号注册类任务后置，优先完成架构与工具链
6. **所有产出统一纳入本GitHub仓库管理**
