# 热点捕捉实战示例（Trend Scout 使用）

当Boss发出“启动新一轮热点捕捉”时，按以下方式执行：

## 推荐执行步骤

1. 使用 web_search 查询：
   - “今日热搜”
   - “微博热搜”
   - “抖音热点”
   - 当前日期 + 热点

2. 使用 x_keyword_search 或 x_semantic_search 验证讨论热度

3. 对候选进行快速过滤：
   - 排除强政治、色情、赌博、高争议
   - 优先选择可做成简单挑战/问答/点击的题材
   - 评估结果页是否容易产生分享欲

4. 输出标准格式（见 Trend Scout 提示词）

## 示例输出结构

**候选1**：XXX热点  
- 热度持续性：8  
- 可玩性：7  
- 分享欲：9  
- 合规风险：2  
- 建议类型：quiz / challenge  
- 理由：……

**最终推荐**：候选X，因为……
