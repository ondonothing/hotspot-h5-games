# 模板配置示例说明

以 Quiz 模板为例，核心配置在 JS 的 GAME_CONFIG 对象：

```js
const GAME_CONFIG = {
  title: "热点问答挑战",          // 游戏标题
  questions: [                    // 题目数组
    {
      q: "问题文案",
      options: ["A", "B", "C", "D"],
      answer: 0                   // 正确答案索引
    }
  ],
  titles: [                       // 结果称号
    { min: 0, max: 1, title: "称号", desc: "描述" }
  ]
};
```

Challenge / Clicker 同理，修改对应 CONFIG 对象中的文案与参数即可快速换皮适配新热点。

拿到 Game ID 后，只需在广告位注释处按说明接入SDK，无需大改结构。
